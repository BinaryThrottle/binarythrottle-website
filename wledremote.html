WLED Remote

Control your WLED lighting system
With Optional OFFLINE Voice Control

A 2.8″ touchscreen in a slim line case, running BinaryThrottle’s WLED Remote firmware. Control Your WLED lights with a dedicated remote. Optional offline voice control module, desk mount and wall mount.

What it controls

  • Colours
  • Presets
  • Effects
  • Brightness
  • Groups of WLEDs
  • Optional voice control with an additional kit (DF2301Q voice module)

What it connects to

  • WLED Over Wi-Fi

Setup help

  1. Configure WLED(s) using the official app
  2. Set presets and Sync
  3. Join Wi-Fi
  4. Enter WLED IP (from app)
  5. Voice control requires additional kit
